# Лендинг iBuild

Лендинг статический. Для локального просмотра из этой папки:

```sh
python3 -m http.server 18743 --bind 127.0.0.1
```

Ссылки «Войти» и «Подать заявку» ведут в приложение на `/#/login` и `/#/register`. На общем домене разместите лендинг по отдельному пути, сохранив приложение в корне. Если у лендинга отдельный домен, задайте `window.IBUILD_APP_URL` с адресом приложения до загрузки `script.js`. Статический локальный предпросмотр не запускает приложение.

## Экраны процесса

PNG в `assets/screens/` — снимки реальных Flutter-виджетов с тестовыми данными, без подключения к базе или внешним сервисам. Чтобы обновить их после изменений интерфейса, из папки `app/` выполните:

```sh
flutter build web --release --no-web-resources-cdn
IBUILD_SHOTS_DIR="$PWD/../landing/assets/screens" flutter test tool/landing_screens_test.dart
```

Сценарий использует шрифт Onest из приложения и шрифт иконок из веб-сборки.
