# Лендинг iBuild

Лендинг статический. Для локального просмотра из этой папки:

```sh
python3 -m http.server 18743 --bind 127.0.0.1
```

Ссылки «Войти» и «Подать заявку» ведут в приложение на `/#/login` и `/#/register`. На общем домене разместите лендинг по отдельному пути, сохранив приложение в корне. Если у лендинга отдельный домен, задайте `window.IBUILD_APP_URL` с адресом приложения до загрузки `script.js`. Статический локальный предпросмотр не запускает приложение.

## Экраны процесса

PNG в `assets/screens/` — снимки реальных Flutter-виджетов с тестовыми данными, без подключения к базе или внешним сервисам. Чтобы обновить их после изменений интерфейса, из папки `app/` выполните:

```sh
flutter build web --release --no-web-resources-cdn
IBUILD_SHOTS_DIR="$PWD/../landing/assets/screens" flutter test tool/landing_screens_test.dart
```

Сценарий использует шрифт Onest из приложения и шрифт иконок из веб-сборки.

## Структура

`index.html` — основной лендинг: скролл-анимации, параллакс и живое демо интерфейса.
Предыдущая версия сохранена как `index-v1.html` и продолжает работать со своими
`styles.css`, `script.js` и `i18n.js`. Обе используют одни и те же ассеты.

```sh
python3 -m http.server 18743 --bind 127.0.0.1
# http://127.0.0.1:18743/          — основной
# http://127.0.0.1:18743/index-v1.html — предыдущий
```

| Файл | Что внутри |
| --- | --- |
| `index.html` | Разметка. Тексты подставляются по `data-i18n`, скриншоты — по `data-shot`. |
| `v2.css` | Оформление и вся анимация на CSS. |
| `v2.js` | Один rAF-цикл на скролл и курсор, IntersectionObserver на появление блоков. Без зависимостей. |
| `v2-i18n.js` | Тексты на RU, EN и UZ. |
| `index-v1.html`, `styles.css`, `script.js`, `i18n.js` | Предыдущая версия. |

Имена `v2.*` оставлены как есть, чтобы не пересекаться с файлами старой версии.
Когда `index-v1.html` станет не нужен, их можно переименовать вместе с ним.

Ссылки «Войти» и «Подать заявку» помечены `data-app` и переписываются через
`window.IBUILD_APP_URL`, как и в предыдущей версии.

### Скриншоты по языкам

`assets/screens/<ru|en|uz>/` — один набор на каждый язык интерфейса. Основной лендинг
подставляет набор под выбранный язык, `index-v1.html` продолжает брать плоские файлы
в `assets/screens/`. Генератор пишет и то и другое:

```sh
cd ../app
IBUILD_SHOTS_DIR="$PWD/../landing/assets/screens" flutter test tool/landing_screens_test.dart
```

Переключается только язык интерфейса. Названия объекта, компаний и людей в демо-данных
(`test/bank_fixtures.dart`) остаются русскими на всех трёх наборах.

### Тексты

RU и EN написаны под этот лендинг. UZ собран из строк предыдущей версии (помечены `v1`)
и терминологии самого приложения из `lib/l10n.dart`; новые строки стоит вычитать носителю.
Все три языка заполнены целиком — ключей без перевода нет.

### Анимация

Всё выключается само при `prefers-reduced-motion: reduce`.

Залипающий блок «Путь одного транша» занимает 420vh: четыре экрана, на каждом подсветка
области и курсор. Координаты областей — в `STEPS` в `v2.js`, в процентах от снимка 1920×1140.

Заголовок с классом `kin` прячет свои слова под маской до тех пор, пока на нём не появится
`is-in`, поэтому такому заголовку нужен и класс `reveal`. На всякий случай `v2.js` наблюдает
за всеми `h2.kin`, даже если `reveal` забыли — иначе заголовок просто не покажется.

Остальное: полоса прогресса чтения сверху, заголовки выезжают по словам из-под маски,
счётчики досчитываются при появлении, бегущая строка собирается из уже переведённых
ключей (новых строк не требует), карточки наклоняются под курсором, кнопки магнитятся,
тёмный блок подсвечивается под курсором, по карточке «К выплате» проходит блик.

Первый экран уходит в белый через `.hero-fade` — градиент высотой 46vh поверх фона, под
контентом. Поэтому у `.hero-in` и `.scroll-cue` задан `z-index`, а у секции «цифры»
убрана верхняя граница: иначе на стыке появлялась бы полоса.
