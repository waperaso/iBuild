# iBuild MVP — зафиксировано 12 октября 2026

Пилот — одна девелоперская компания. Интерфейс русский. Валюта UZS. Вход только по учётным записям, которые создаёт оператор.

## Роли

Одна учётная запись — одна роль на объекте. Подрядчик не проверяет свою заявку.

| Роль | Код | Может | Не может |
|---|---|---|---|
| Директор | `director` | Создавать объект своей компании, позже согласовывать и фиксировать оплату | Видеть чужую компанию |
| Подрядчик | `contractor` | Видеть назначенные объекты, позже подавать свои заявки | Видеть чужие заявки и создавать объект |
| Технадзор | `tech` | Смотреть объект и позже проверять фото | Согласовывать выплату и отмечать оплату |
| Наблюдатель | `observer` | Смотреть явно назначенный объект | Менять что-либо |

Скрытие кнопки в интерфейсе не защита. Сервер проверяет роль и членство на каждом запросе.

## Статусы заявки

Код в API и подпись на экране. На этой неделе заявок ещё нет, подписи уже заданы.

| Код | Экран | Сумма |
|---|---|---|
| `draft` | Черновик | Не резервируется |
| `submitted` | На проверке технадзора | Резерв |
| `tech_approved` | На согласовании директора | Остаётся в резерве |
| `approved` | Одобрена к оплате | Остаётся в резерве до записи платежа |
| `paid` | Оплачена | Уходит из резерва в оплаченное |
| `rejected` | Отклонена | Резерв освобождается |
| `cancelled` | Отменена | Резерв освобождается |

Других переходов нет. Отказ, отмена и оплата — конечные состояния.

## Главный сценарий, который эта неделя только обрамляет

Создать объект → внести бюджет → назначить участников → подать заявку с фото → проверить технадзором → согласовать директором → оплатить вне iBuild → записать факт оплаты → увидеть остаток.

Неделя 1 заканчивается на входе, двух изолированных компаниях и каркасе шести экранов. Неделя 2 добавляет смету, подрядчиков, участников и четыре суммы на карточке объекта. Заявка с фото, решение технадзора и запись оплаты остаются дальше.

## В пилоте нет

Прямые платежи, банковские форматы, XML и ЭДО, ЭЦП, государственные API, Telegram, AI, нативные приложения, офлайн, сложная аналитика, частичные оплаты, авансы, удержания, конструктор согласований, публичная регистрация и SMS.

Деньги в API — строки `NUMERIC(18,2)`, например `"12500000.00"`. Арифметика Flutter `double` запрещена.
