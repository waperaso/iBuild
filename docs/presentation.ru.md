# Показ продукта iBuild

Стенд: http://localhost:8080. Пароль всех демо-логинов — из `.env` (`SEED_PASSWORD`), по умолчанию `123456`.
Перед показом: `./scripts/backup.sh`, затем `docker compose up -d --build` и `curl localhost:8080/api/ready`.

## Идея в одной фразе
Застройщик просит деньги банка на стройку по мере готовности работ. Банк видит всё в одном месте: что построено, что подтвердил эксперт, кто согласовал и когда платить. Каждое действие остаётся в журнале.

## Сценарий на 12–15 минут

1. **Регистрация (1 мин).** Страница входа → «Регистрация» → «Я застройщик». Показать форму: реквизиты с валютными счетами, документы, согласие. Не отправлять.
2. **Админ платформы** `a.admin` (2 мин). «Обзор»: что требует внимания, заявки. «Компании», «Пользователи» (отключить, сбросить пароль, временный пароль виден один раз), «События», «Почта», «Система» (бэкап, миграции).
3. **Застройщик** `a.director` (2 мин). Объект, смета, заявка на оплату, фото, осмотр, документы.
4. **Банк: очередь** `a.observer` (2 мин). Четыре вкладки, срок банка («Прошло 1 дн. 4 ч · срок банка 2 дн.»), цвет сигналов. Открыть транш: этапы, пять сумм, сигналы, свёрнутые статьи.
5. **Решение по строке** (1 мин). Обоснование, частичное решение. Попробовать выдать больше подтверждённого: запрещено.
6. **Согласование** `a.head1`, `a.committee1…3` (2 мин). Маршрут, кворум, нельзя голосовать за свой транш. ЭЦП и платёж по заблокированному траншу недоступны.
7. **Портфель, объекты, осмотры, застройщики** `a.head1` (2 мин). Сигналы внимания, «напомнить» (письмо уходит в очередь «Почта»), закрытие осмотра экспертом `a.expert`.
8. **Отчёты** `a.risk` (1 мин). Каталог, отчёт, выгрузка XLSX/PDF/CSV, «Отправить сейчас».
9. **Правила и маршруты** `a.bankadmin` (1 мин). Четыре вкладки; изменить порог → «Сохранить как версию N+1»; новые транши идут по новой версии, идущие остаются на старой. Раздел «Документы»: смена «блок / предупреждение» для акта или счёта меняет сигнал в траншах.
10. **Журнал** `a.bankadmin` (30 сек). Кто, когда, что менял.

## Что сказать честно
- Платёжный шлюз и ЭЦП в демо не подключены: кнопки показывают, где они встанут.
- Почта: без SMTP письма копятся в очереди «Почта». С SMTP уходят сразу.
- Данные демо заполнены сидом; на боевой базе их нет (`SEED_ON_START=false`).

## Если что-то пошло не так
- Страница не открывается: `docker compose ps`, `docker compose logs api --tail 50`.
- Сломали данные: `./scripts/restore.sh backups/<папка>`.
